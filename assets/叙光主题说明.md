# 叙光主题

暖白背景 #FFF7F0，纸白表单 #FFFEFA，深梅紫文字 #3C203A，梅紫主按钮 #963E72，暖金进度与重点 #D99A2B，淡金高亮 #FFE5AD。

界面色值统一由 theme.py 管理。覆盖主界面、历史列表、设置、音色制作与管理、视频导出、按钮悬停、文本选择、播放高亮、滑块和进度条。系统原生文件选择器与消息框保留 Windows 外观。

图标采用简洁书页与四角光芒设计，使用程序化图形绘制，源文件为 work/design_xuguang_icon.py；PNG 和多尺寸 ICO 位于本目录。EXE 内嵌图标和 Tk 主窗口及子窗口使用同一图标。

窗口标题为“叙光”。主题更新不修改已生成的音频与视频。
